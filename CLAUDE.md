# Working on ai-template

This repository is an additive collection of AI skills and optional examples.
These instructions govern this collection, not repositories using its skills.

Preserve destination repositories' README content, licenses, layouts, build and
test commands, and assistant configuration. Adopt only the requested capability.
Use `skills/narrative/SKILL.md` for requested story or chronicle work.

Keep examples inert under `examples/`; do not install MCP servers or enforce
workflow phases by default. `starters/` contains optional new-project guidance.
There is no mandatory Makefile, directory layout, coverage threshold, or story.
For documentation changes, check links and diffs; run relevant validation for any
scripts changed. Do not invent build or test infrastructure for this collection.
